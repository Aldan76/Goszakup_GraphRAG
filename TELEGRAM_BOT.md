# Telegram Bot для государственных закупок

Полнофункциональный Telegram бот для поиска и анализа информации по государственным закупкам с использованием GraphRAG.

## 🚀 Установка и запуск

### Предварительные требования
- Python 3.10+
- Neo4j 5.0+
- OpenAI API ключ
- Telegram Bot Token (от @BotFather)

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Конфигурация

1. Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```

2. Заполните переменные окружения:
```env
# Telegram
TELEGRAM_BOT_TOKEN=ваш_токен_здесь

# Neo4j
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=password

# OpenAI
OPENAI_API_KEY=ваш_ключ_здесь

# Админы (ID пользователей через запятую)
TELEGRAM_ADMIN_IDS=123456789,987654321
```

### Запуск

```bash
# Запуск бота
python -m telegram_bot

# Или
python -m telegram_bot.__main__
```

## 📋 Команды бота

### Публичные команды

| Команда | Описание | Пример |
|---------|---------|---------|
| `/start` | Приветствие и справка | `/start` |

| Команда | Описание | Пример |

## 🔧 Архитектура

```
Telegram User
    ↓
telegram_bot/bot.py (GoszakupBot)
    ↓
rag_engine/rag_chain.py (RAGChain)
    ↓
┌─────────────────────────────┐
├─ graph_retriever (Search)   │
├─ embeddings (OpenAI)        │
└─ graph_loader (Neo4j)       │
    ↓
LLM Response (gpt-4/3.5)
    ↓
Telegram User
```

## 📊 Особенности

### Query Processing
1. **Retrieval** - поиск релевантной информации в графе
2. **Embedding** - генерация embeddings для семантического поиска
3. **LLM** - генерация ответа через GPT-4
4. **Formatting** - форматирование для Telegram

### Maintenance Mode
- Включение/выключение бота для администраторов
- Кастомные сообщения о обслуживании
- Автоматическое отключение всех команд

### Session Management
- Отслеживание истории запросов
- Поддержка многопользовательского доступа
- Асинхронная обработка запросов

## 📝 Логирование

Логи записываются в `logs/app.log` с уровнем, заданным в `.env`:
```env
LOG_LEVEL=INFO
```

Уровни логирования:
- `DEBUG` - детальная информация для отладки
- `INFO` - информационные сообщения
- `WARNING` - предупреждения
- `ERROR` - ошибки

## 🚨 Обработка ошибок

### Ошибки подключения Neo4j
- Проверьте, что Neo4j запущен
- Проверьте URI, user, password в .env

### Ошибки OpenAI API
- Проверьте, что API ключ корректен
- Проверьте лимиты на аккаунте OpenAI
- Бот автоматически переключится на fallback модель (GPT-3.5)

### Ошибки подключения Telegram
- Проверьте, что токен корректен
- Проверьте интернет соединение

## 🔐 Безопасность

- Токен бота хранится в `.env` (не коммитьте в git)
- Sensitive данные не логируются
- Проверка прав администратора для команд управления
- Валидация пользовательских вводов

## 📞 Поддержка

Для проблем и вопросов:
1. Проверьте логи в `logs/app.log`
2. Проверьте конфигурацию в `.env`
3. Убедитесь, что все сервисы запущены (Neo4j, OpenAI API доступна)
